> 状態: 下書き。「未決事項」の節は、議論して決める項目。

## 概要
寿命とお金の2つを持つダークな世界で、法律と制度の隙間を突いて稼ぐ。死ぬと、性質の一部を受け継いだ次のプレイヤーが生まれる。

## 着想
- Schedule I: 違法な商売を小さく始めて大きくしていく手触り
- 映画「TIME」: 寿命が目に見えて減っていく緊張感。寿命を買い溜めて長生きする富豪
- Breaking Bad の「人消し屋」、身分証の偽造屋: 制度の裏側で働く専門家たち

## 柱（ぶらさないもの）
1. **死の重さが変わっていく**: 序盤、死は避けられない。稼ぐほど寿命を買えるようになり、後半の死は「新しいキャラクターで始め直すか」程度の選択肢になる
2. **世代を継ぐ**: 死ぬと、性質の一部（遺伝情報）を受け継いだ次のプレイヤーが生まれる
3. **制度をハックする**: 法律は国と時代で違い、時代とともに変わる。その差が稼ぎ口になる
4. **寿命とお金は別物**: どちらも資源だが、性質が違う（下記）

## 世界の前提
- この世界の生き物は**無性生殖**で増える。結婚、性、恋愛、子育ては存在しない
  - 狙い: 恋愛や受精の仕組みを作らずに、世代交代と遺伝だけを扱う
- **ゲーム内の時間は現実の時間と同じ速さで進む**
  - 1時間の寿命は、実際に1時間遊べる長さ
  - 年単位の寿命は、実質的に死なない長さになる。これが後半の「死は選択肢」につながる
  - 刑期のように年単位で過ぎる出来事は、ベッドで刑期を全うする時のように一瞬で飛ばす

## 2つの資源

| | 寿命 | お金 |
|---|---|---|
| 増やす | お金で買う（医療、闇の取引など）。序盤は手が届かない | 働く、違法な商売 |
| 減る | 時間の経過、刑期、嗜好品、危険な行為 | 支払い、罰金、没収 |
| 死後 | 残らない | **残せる**（ただし相続の制度が壁になる） |
| 汚れ | ない | ある（汚れた金は使うと足がつく → 洗浄が必要） |

- 「寿命を払ってお金を得る」（働く時間、服役）、「お金を払って寿命を得る」（医療）という交換を用意する
- 序盤はお金が足りず、寿命を買えないので死ぬ。後半は寿命を買い続けられるので死なずに済む
- **相続**: 財産を次の世代へどう渡すかに、相続税、タックスヘイブン、名義の偽造、マネーロンダリングがつながる

## コアループ
```
生まれる（受け継いだ性質で始まる）
  → 稼ぐ（合法 / 違法）
  → 洗浄し、隠し、残す / 寿命を買う
  → 死ぬ（序盤は避けられない。後半は選べる）
  → 性質と財産が次の世代へ → 時代が進み、法律が変わる
```

## 遺伝情報（性質）
- 死ぬと、性質のいくつかが次のプレイヤーに受け継がれる。すべてではない
- 生き方は遺伝に影響しない。受け継ぐのは生まれ持った性質だけ
- 寿命の長さは性質にしない（基礎寿命の概念は導入しない）
- 性質の例（案）:
  - 器用さ: 偽造や加工の精度
  - 人相: 検問や警察に疑われやすいかどうか
  - 依存しやすさ: 嗜好品の効果と中毒のなりやすさ

## 時代と法律
- 世代が進むと時代も進む。法律は「国 × 時代」の表として持つ
  - 例: ある物が合法か違法か、刑期、罰金、相続税率、口座の秘匿性
- 前の世代で有効だった稼ぎ方が、次の世代では違法になっていたり、逆に解禁されていたりする

## チュートリアル（最初の人生）
目的: **死と受け継ぎを体験させる**。操作の説明はついでに行う。

1. 独房で目を覚ます。寿命は「2年と1時間」。目標「刑期を全うする」 *(実装済み)*
2. ベッドで刑期を全うする。寿命が2年減り、残りは1時間。扉が開く *(実装済み)*
3. 目標「死ぬ」 *(目標だけ実装済み)*
4. 扉の外にある、寿命を縮める道具を拾い、インベントリに入れる *(実装済み: タバコ、ロープ)*
5. インベントリから使う。寿命が大きく減る演出が出て、死ぬ *(実装済み)*
6. 暗転し、受け継いだ性質が示される。次の世代で本編が始まる *(暗転と世代交代は実装済み。性質は保留)*

## 2世代目以降（本編）
- プレイヤーの本来のアバター。刑務所から離れた別の場所（今は仮の路地）から始まる *(実装済み)*
- 寿命は60分（仮） *(実装済み)*
- 刑期も目標もない

### 最初の体験: 合法の店舗経営
Supermarket Simulator のような素直な経営から始める。店舗を買い、署名した営業許可証とレジを置き、営業を始める。

- **違法から始めない理由**: Schedule I の麻薬は「一応悪いことになっている」以上の意味が薄く、合法の商売でも体験はあまり変わらない。このゲームの中心は、商売の中身ではなく制度のハックにある
- **合法の手続きが、後でハックする対象になる**: 最初に正規の手続きを体験させておくと、後で抜け道を使ったときに「何を省いたのか」がプレイヤーに伝わる

| 合法の手続き（最初） | 後のハック |
|---|---|
| 営業許可を申請し、署名して掲げる | 許可証を捏造する |
| 売上を申告し、税を払う | 脱税、タックスヘイブン |
| 売上を口座に入れる | 汚れた金を店の売上に混ぜて洗浄する |

- 寿命は現実の時間で減るので、**正規の手続きにかかる待ち時間は、そのまま寿命の消費になる**。抜け道の価値は「お金」だけでなく「時間」でも測れる

### 寿命を縮める道具（案）
道具ごとに「どれだけ減るか」と「代わりに何が得られるか」を変えると、本編でもそのまま使える。

| 道具 | 寿命 | 本編での役割（案） |
|---|---|---|
| タバコ | 少し減る | 日常の嗜好品。気分や集中が上がる代わりに寿命を削る。依存がある |
| ガラス片 | 中くらい | 即席の武器、道具 |
| ロープ | 死ぬ | 道具としても使える（登る、縛る） |
| 拳銃 | 死ぬ | 武器。持っているだけで違法な国もある |

- 待っていても1時間で死ぬ。道具は「待つ以外の選び方」をプレイヤーに与えるもの
- 自死の表現をどこまで直接描くか（暗転で済ませる、音だけにするなど）は、年齢区分やストアの審査にも関わるので早めに決める

### 建物が地面から現れる演出（アイデア）

- 物件を探して買う手間を、演出として気持ちよく省ける
