## 概要
寿命とお金の2つを持つダークな世界で、法律と制度の隙間を突いて稼ぐ。死ぬと、性質の一部を受け継いだ次のプレイヤーが生まれる。

## 着想
- Schedule I: 違法な商売を小さく始めて大きくしていく手触り
- 映画「TIME」: 寿命が目に見えて減っていく緊張感。寿命を買い溜めて長生きする富豪
- Breaking Bad の「人消し屋」、身分証の偽造屋: 制度の裏側で働く専門家たち
- 映画「インセプション」: 夢の世界を改変しすぎると、住人の関心を集めてしまう

## 柱（ぶらさないもの）
1. **死の重さが変わっていく**: 序盤、死は避けられない。稼ぐほど寿命を買えるようになり、後半の死は「新しいキャラクターで始め直すか」程度の選択肢になる
2. **世代を継ぐ**: 死ぬと、性質の一部（遺伝情報）を受け継いだ次のプレイヤーが生まれる
3. **制度をハックする**: 法律は国と時代で違い、時代とともに変わる。その差が稼ぎ口になる
4. **寿命とお金は別物**: どちらも資源だが、性質が違う（下記）

## 世界の前提
- この世界の生き物は**無性生殖**で増える。結婚、性、恋愛、子育ては存在しない
  - 狙い: 恋愛や受精の仕組みを作らずに、世代交代と遺伝だけを扱う

## 時間の流れ（案）
「現実の1分 = ゲームの1分」は仮の前提だった。遊ぶ時間（数時間）、商売の時間（1日）、人生の時間（数年〜数十年）は長さが違いすぎて、1つの比率では同時に満たせないため、次の2本立てにする案がある。

- **普段の流れ**: ほどほどの速さで進む（例: 現実1秒 = ゲーム1分で、1日が現実の24分）。店の1日を実際に回せる
- **寿命を払って飛ばす**: 大きく時間を進める時は、寿命を払って一気に飛ばす。飛ばした分だけ世界全体も進む
  - 刑期を全うする *(実装済み: ベッドで2年を飛ばす)*
  - 眠る、許可が下りるのを待つ
  - 設備に寿命を捧げて営業を回す（下記「店舗経営」）

これにより:
- **正規の手続きの待ち時間が、文字どおり寿命の消費になる**。偽造の許可証なら待たずに済む
- 人生の時間の大半は飛ばすことで使われ、実際に遊ぶのは数時間でも、寿命は年単位で意味を持つ
- 飛ばした分だけ時代も進む。寿命を早く燃やす人ほど、法律の変化を早く体験する

今の試作は「寿命の1秒 = 現実の1秒」で作っている。比率を決めたら、寿命の数値（チュートリアルの出所後1時間、2世代目の2時間）を決め直す。

## 2つの資源

| | 寿命 | お金 |
|---|---|---|
| 増やす | お金で買う（医療、闇の取引など）。序盤は手が届かない | 働く、違法な商売 |
| 減る | 時間の経過、刑期、嗜好品、危険な行為 | 支払い、罰金、没収 |
| 死後 | 残らない | **残せる**（ただし相続の制度が壁になる） |
| 汚れ | ない | ある（汚れた金は使うと足がつく → 洗浄が必要） |
| 形 | 数字 | **汚れた金は物、きれいな金は数字**（下記「物理の持ち物」） |

- 「寿命を払ってお金を得る」（働く時間、服役）、「お金を払って寿命を得る」（医療）という交換を用意する
- 序盤はお金が足りず、寿命を買えないので死ぬ。後半は寿命を買い続けられるので死なずに済む
- **相続**: 財産を次の世代へどう渡すかに、相続税、タックスヘイブン、名義の偽造、マネーロンダリングがつながる

## コアループ
```
生まれる（受け継いだ性質で始まる）
  → 稼ぐ（合法 / 違法）
  → 洗浄し、隠し、残す / 寿命を買う
  → 死ぬ（序盤は避けられない。後半は選べる）
  → 性質と財産が次の世代へ → 時代が進み、法律が変わる
```

## 遺伝情報（性質）
- 死ぬと、性質のいくつかが次のプレイヤーに受け継がれる。すべてではない
- 生き方は遺伝に影響しない。受け継ぐのは生まれ持った性質だけ
- 寿命の長さは性質にしない（基礎寿命の概念は導入しない）
- 性質の例（案）:
  - 器用さ: 偽造や加工の精度
  - 人相: 検問や警察に疑われやすいかどうか
  - 依存しやすさ: 嗜好品の効果と中毒のなりやすさ

## 時代と法律
- 世代が進むと時代も進む。法律は「国 × 時代」の表として持つ
  - 例: ある物が合法か違法か、刑期、罰金、相続税率、口座の秘匿性
- 前の世代で有効だった稼ぎ方が、次の世代では違法になっていたり、逆に解禁されていたりする

## 2世代目以降（本編）

### 最初の体験: 合法の店舗経営
Supermarket Simulator のような素直な経営から始める。店舗を建て、署名した営業許可証とレジを置き、営業を始める。

- **違法から始めない理由**: Schedule I の麻薬は「一応悪いことになっている」以上の意味が薄く、合法の商売でも体験はあまり変わらない。このゲームの中心は、商売の中身ではなく制度のハックにある
- **合法の手続きが、後でハックする対象になる**: 最初に正規の手続きを体験させておくと、後で抜け道を使ったときに「何を省いたのか」がプレイヤーに伝わる

| 合法の手続き（最初） | 後のハック |
|---|---|
| 営業許可を申請し、署名して掲げる | 許可証を捏造する |
| 売上を申告し、税を払う | 脱税、タックスヘイブン |
| 売上を口座に入れる | 汚れた金を店の売上に混ぜて洗浄する |

#### 経営の数字の作り方
Supermarket Simulator や Schedule I では、人を雇って自動化すると生産速度が分からず、どこがボトルネックか見えなくなる。これらのゲームは途中で「作業ゲーム」から「経営ゲーム」に変わるのに、経営の道具を渡さない。このゲームでは、決める段階に入ったら道具を渡す。

- **処理速度は決めて明記する**（Factorio のように）。例: 2級販売士のレジは客1人に2秒 = 30人/分。店員の速さは隠れた値にせず、免許の等級として見せる
- **客足も決めておく**。立地、評判、時代、法律から「営業1回に何人来るか」が決まる。ランダムなのは来る時刻の見た目だけで、合計は変わらない
- **単位は「営業1回」**（例: ゲーム内の1日）。処理しきれなかった客は、帰って売上を失うか、残業で処理してそのぶん給料がかかる
- **裏の計算と表の NPC を切り離す**。裏（ドメイン層）では店を「持ち場と行列の連なり」として計算し、NPC はその結果を演じる役者にする。NPC の歩き方に数字が左右されず、画面を描かずに一瞬で何時間ぶんでも計算でき、テストと数値調整がしやすい
- **見せ方**: 詰まっている所に行列ができる（目で分かる）ことと、持ち場ごとの「能力・実績・稼働率・行列」（数字）の両方。稼働率がほぼ100%で行列がある所がボトルネック
- **自動化は望ましい**。店を回すことは手段で、自動化はプレイヤーの手を空けて本題（制度のハック）に向かわせる。自動化した後の「決めること」は、法律の変化、税務調査、競合といった制度の側から来る

#### 帳簿
- 生産速度や売上を見る道具は、画面の UI ではなく、この世界の**帳簿**として置く。帳簿を付ける（経理を雇う、計算士の免許を取る）と見えるようになる
- 序盤は帳簿がないので、手作業の感触を損なわない
- 帳簿は**税務調査で調べられる書類そのもの**でもある。本当の数字を付ければ経営に役立つが、調査で全部見られる。ごまかせば税は減るが、自分も本当の数字が分からなくなる（二重帳簿）

#### 洗浄の限度
- 客足と処理能力が決まっていて、調べる側にも分かるので、申告した売上の不自然さを判定できる
  - 売上が「客足 × 客単価」を大きく超える → 不自然
  - 売上がレジの処理能力を超える → ありえない
- つまり、**怪しまれずに洗浄できる額が、店の数字から決まる**。増やしたければ客足やレジを増やす、客単価の高い店にする、あるいは客足の記録を偽造する

#### 設備は寿命で動く（案）
- 「寿命を1分捧げると、設備の1分ぶんの生産が即座に手に入る」案がある
- 設備が普段の時間でも勝手に動くなら、捧げる方が常に得になる（同じ寿命で二重に手に入る）ので、捧げた分は割り引くか、代償を付ける必要がある
- 一番合いそうなのは、**設備はそもそも寿命を燃料にしてしか動かない**形。生産速度がそのまま「寿命1分あたりの交換レート」になり、放置して待つだけの時間もなくなる。店員に払うのも寿命にできる（TIME そのもの）
- 数値は、「寿命 → 物 → お金 → 寿命」の一周が**普通にやると1未満（損）、制度をハックした時だけ1を超える**ように組む。普通の手段で1を超えると、寿命が潤沢になって罰が効かなくなる問題が序盤から起きる

### 建築
- インセプションの夢の世界のように、ゲームだからこそ建物を自由に出せる。店舗が地面からぬるりと現れる *(実装済み: 砂ぼこり付き)*
- **設計図**を使うと半透明の影で建つ位置を確かめられ、建てられる所は緑、自分と重なる所は赤になる。左クリックで建て、右クリックでやめる *(実装済み)*
- 現実でも、建物には設計図と建築確認（建築の許可）が要る。設計図は、そのまま「制度」の入り口になる（正規の許可で建てる → 後で許可を偽造する）
- 建築家の免許で使える能力にする案がある（下記「免許」）
- 写実寄りのダークな世界観と、この超常的な演出をどう両立させるかは未決
- 今は平らな面ならどこにでも建つ（木箱の上も）。どこを「建ててよい地面」とするかは、土地の所有や地面士の免許とつなげて決める

## 周りの目（注目度）
インセプションで夢を改変しすぎると住人の関心を集めてしまうように、目立つ物を持っていると周りの人に見られる。「妙にみんなこっちを見てくるな」という居心地の悪さを表す *(実装済み: 実験)*

- 道具ごとに**目立ち度**（0〜1）がある。持ち物全体の目立ち度は、一番目立つ物で決まる（拳銃は1）
- 人は、視界（15m、視野120°、壁で遮られる）に目立つ物を持ったプレイヤーが入ると気にし始め、見えないとゆっくり冷める
- 反応の段階: 気にしない → **顔だけで追う** → **立ち止まって体ごと向き直る**
- 立ち止まって見ている人を見た周りの人も、**釣られて顔で追う**。ただし釣られただけでは立ち止まらない（見ている人同士で高め合って、群衆がいつまでも見続けるのを防ぐため）
- 注目度のゲージは画面に出さない。数字で見せると「居心地の悪さ」ではなく「管理する値」になるため
- 「制度との戦い」の疑いの、目の前で起きる一番小さな版と位置づけられる
- 今後の案: 手に持っているかどうかで目立ち方を変える、バッグに隠せば見えない、建物のせり上がりを見た人の注目度を上げる、近づいてくる・通報する段階

## 物理の持ち物
物理で転がる物を手に持って運び、バッグに詰める *(実装済み: 実験。ダッフルバッグと札束20個)*

- E で手に持ち、もう一度 E で離す。F でバッグを開け閉めする
- **閉じたバッグの中身は物理を止め**、バッグと一緒に動く。開けると閉じた時の位置から物理が続く。閉じている間は中身同士の衝突を計算しなくて済む
- ホットキー分の物は今までどおり運べる。多くの物（例: 札束20個）を運ぶ時に、それを束ねるバッグが要る

### 試した結果と方針
- 触った感想は「悪くないが、この方が楽しいと断定できるほどではない」。今の試作には、物理であることが意味を持つ場面がまだないため
- 仕組みそのものは新しくない（VR の Into the Radius、Bonelab、Half-Life: Alyx、非 VR の My Summer Car、R.E.P.O. など）
- **全部を物理にはしない。現金・禁制品・証拠品と、それを入れる入れ物だけを物理にする**。日常の道具はホットキーの枠で扱う
- **汚れた金は物、きれいな金は数字**。現金には重さと大きさがあり、物である間は隠す・運ぶ・見られる・奪われる・検問で開けられる危険がつきまとう。洗浄とは、それを口座の数字に変えること。洗浄する理由をプレイヤーに体で分からせる
- インベントリ UI を完全になくすかは、物理であることが効いてくる仕組み（注目度との連携、検問や家宅捜索、洗浄）ができてから、改めて触って判断する
- 詰める作業の面倒さは、バッグの口に吸い込む、数個まとめて持つ、などで減らせる。ただし「時間 = 寿命」のテーマから、あえて残す手もある

## 制度との戦い
GTA の手配度のような「その場で追われる」形ではなく、「記録が残り、不自然さが疑われ、後から調べられる」形にする。偽造、洗浄、脱税は、その場では誰も気づかない犯罪だから。

1. **記録**: 書類、口座、取引の記録が残る
2. **疑い**: 記録の食い違いや不自然さ（店の規模に比べて多すぎる売上など）が疑いとしてたまる
3. **調査**: 疑いが一定を超えると、少し遅れて税務調査や捜査が入る
4. **裁き**: 帳簿が合わなければ罰金、没収、服役

寿命と時間のテーマにつながる要素:
- 時効: 長生きできる者ほど逃げ切れる
- 管轄と引き渡し: 国ごとに法律が違い、引き渡し条約のない国へ逃げられる
- 身分: 前科は身分に付く。人消し屋や偽造で身分を替えられる
- 死: 次の世代は前科がない。ただし相続の流れから足取りを追われうる

### 寿命やお金が潤沢になると罰が効かなくなる問題
- 罰の重さは寿命よりも、**財産・身分・相続**にかける
  - 罰金を資産に比例させる（実在の日数罰金制のように）
  - 没収や追徴で、次の世代へ残すはずの財産を奪う
  - 前科による免許の剥奪、口座の凍結、出国禁止など、寿命の長さに関係なく効く罰
- 服役中も世界は進む。出所すると法律が変わり、店は競合に取られている。逆に、服役して時代が変わるのを待つという抜け道にもなる
- 規模が大きくなるほど、取り締まる側も地方の警察から国、国際機関へと強くなる

## 免許（ライセンス）
スキルツリーに当たる仕組み。経験値ではなく、**実績を解除して、役所で手続きをして**免許を取る。
- 例: 2級清掃士になりたければ、ゴミを50個集めて清掃局で手続きする
- 免許認定試験を受けることで、ライセンスツリーのノードをアンロックできる。免許によっては、試験が一般的なゲームのボスのような位置づけになっていることもある
- 販売士のルートを進むか、清掃士として成り上がるか、など、いくつかのツリーから選べる
- 免許を剥奪された者は、5年経過しないと（5年分の寿命を差し出さないと）再取得できない
- 免許の取得や剥奪は、それ自体が「制度」なので、偽造やハックの対象にもなる
- 免許の等級で、店員などの処理速度が決まる（上記「経営の数字の作り方」）

職業の例:
- 人消し屋
- 販売士: 店を開いて物を売る
- 清掃屋: ゴミや死体を処理して稼ぐ
- 建築家: 建物を建てる
- 探知士: 人やアイテムの位置を知る
- 地面士: 土地を管理し操る
- 計算士: シャフリングを使い、機密データを管理・保護する。組織（システム）に属する
- 記号士: 計算士に対抗する集団。工場（ファクトリー）と呼ばれる
- 鍵士（キーマスター）: 様々な場所の鍵を作成する。最終的にはドアを使ってテレポートができる
- 天気予報士: 最終的には天候をコントロールできる
- ランプライター（点灯夫）
