## 調査メモ

### 地面タイルの重なり(2026-09-30)
- キットの十字路(Street_4WayIntersection)とT字路は4車線用。出口は幅12mすべてが車道で、四隅に道路の中心から6〜9mの帯の丸い角の歩道がある。これは Street_4Lane(幅18m = 歩道3m + 車道12m + 歩道3m)とつながる形。2車線用の十字路はキットにない
- 街は、この十字路に Street_2Lane(幅12m = 歩道3m + 車道6m + 歩道3m、歩道は中心から3〜6m)をつないでいた
- そのため、区画の地面(中心から6mの所から、高さ -0.005m)が十字路の角の歩道(6〜9m、上面0m)とほぼ同じ高さで重なり、ちらつく。原点の十字路と Block22 などで見える
- 十字路の出口で、2車線の歩道が途切れていきなり車道になる
- 十字路の実際の大きさは 24.666m だが、生成スクリプトでは 24.67m としていたので、十字路の間隔が1つにつき約4mmずれる
- 街は生成スクリプトで座標を計算して並べており、エディタのスナップは使っていない
